# AlfaGift Sentiment Analysis

This project performs sentiment analysis on AlfaGift user reviews using a BiLSTM (Bidirectional Long Short-Term Memory) model.

## Description

The goal of this project is to classify user reviews into positive or negative sentiments to understand customer satisfaction.

## Features

- Text preprocessing.
- Tokenization and padding.
- BiLSTM model implementation.
- Model performance evaluation.

## Project Structure

```
.
├── docs/               # Additional documentation
├── Alfagift_reviews.csv # Reviews dataset
└── sentiment-review-alfagift-using-bilstm.ipynb # Main notebook
```
