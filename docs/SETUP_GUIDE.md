# Panduan Setup

Panduan ini menjelaskan cara menyiapkan lingkungan untuk menjalankan proyek analisis sentimen AlfaGift.

## Prasyarat

- Python 3.x
- Jupyter Notebook / VS Code

## Langkah-langkah

1. Clone repositori ini.
2. Instal dependensi yang diperlukan:
   ```bash
   pip install pandas numpy scikit-learn tensorflow matplotlib
   ```
3. Buka `sentiment-review-alfagift-using-bilstm.ipynb` di Jupyter Notebook atau VS Code.
4. Jalankan sel-sel dalam notebook secara berurutan.
