# Analisis Sentimen AlfaGift

Proyek ini melakukan analisis sentimen terhadap ulasan pengguna aplikasi AlfaGift menggunakan model BiLSTM (Bidirectional Long Short-Term Memory).

## Deskripsi

Tujuan proyek ini adalah untuk mengklasifikasikan ulasan pengguna menjadi sentimen positif atau negatif guna memahami kepuasan pelanggan.

## Fitur

- Pra-pemrosesan teks (text preprocessing).
- Tokenisasi dan padding.
- Implementasi model BiLSTM.
- Evaluasi performa model.

## Struktur Proyek

```
.
├── docs/               # Dokumentasi tambahan
├── Alfagift_reviews.csv # Dataset ulasan
└── sentiment-review-alfagift-using-bilstm.ipynb # Notebook utama
```
